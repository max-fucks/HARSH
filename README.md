# HARSH &bull; Celestial Universe & Cherry Blossom Odyssey 🌸

> *"We are not merely wanderers under the sky; we are the cosmos observing its own mystery through quiet moments and passing shadows."*

An ultra-luxury, cinematic personal experience crafted with ambient glowing visuals, physics-based cherry blossom storms, deep-space stardust VFX, philosophical reflections, and ambient soundtrack accompaniment.

---

## 🌟 Key Features

- **GOAT Image Glow**: Ambient dynamic radiance that reflects the true tones of every individual photo.
- **Falling Cherry Blossom (Sakura) Engine**: 60 FPS physics-driven fluttering petals with real notch curvature, natural 3D rotation, and responsive cursor wind drift.
- **Deep Cosmic VFX**: Subtle interstellar nebula dust clouds, twinkling micro-stars, and periodic shooting star streaks.
- **12 Curated Chapters & 27-Moment Archive**: Comprehensive luxury gallery featuring interactive 3D perspective tilt and high-definition lightbox viewer.
- **Atmospheric Soundscape**: Integrated romantic ambient soundtrack player with animated rose-gold equalizer wave bars.
- **Philosophical Narrative**: Original, introspective reflections tailored to every scene.

## 🚀 Live Preview & Running Locally

Simply clone the repository and open `index.html` in any modern web browser, or launch a quick local server:

```bash
# Clone the repository
git clone https://github.com/ansh-sm/harsh-universe.git

# Navigate to the folder
cd harsh-universe

# Run local HTTP server
python -m http.server 8000
```
Then visit `http://localhost:8000`.

---

## 🌐 Deploy to GitHub Pages (1-Click)

1. Go to repository **Settings** &rarr; **Pages**.
2. Under **Build and deployment** &rarr; **Branch**, select `main` (or `master`) and folder `/(root)`.
3. Click **Save**. Your site will be live across the globe within minutes at:
   `https://ansh-sm.github.io/harsh-universe/`
